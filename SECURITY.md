# Security

Report a vulnerability privately, through GitHub, to the project the formula installs: for `herdr-pager`, [its Security tab](https://github.com/MaverickHQ/herdr-pager/security), then **Report a vulnerability**. Its `SECURITY.md` says what counts.

A problem with this tap itself, such as a formula naming an archive other than its release's, or the wrong sha256, goes there too. Please don't open a public issue for it.
